# 📝 Test Ishlash (Streamlit Test Tizimi)

Turli fanlar bo'yicha testlarni yechish uchun **Streamlit** ilovasi. Savollar `tests.py` faylda saqlanadi.

---

## ✨ Imkoniyatlar

- 📚 **Fanlar:** umumiy pedagogika, texnologiya, tabiiy fan, ona tili, matematika
- 🎲 **Tasodifiy savollar**
- ✅ **Natijani tekshirish**
- 🔄 **Format normalizatsiyasi:** turli savol formatlarini birxillashtirish

---

## 🛠 Texnologiyalar

| Texnologiya | Maqsad |
|---|---|
| **Python 3.10+** | Asosiy til |
| **Streamlit** | Veb-interfeys |
| **pdfplumber / python-docx** | Savollarni import qilish |

---

## ⚙️ O'rnatish

```bash
git clone https://github.com/dastonbek8747/TEST_ISHLASH.git
cd TEST_ISHLASH
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

---

## ▶️ Ishga tushirish

```bash
streamlit run main.py
```
