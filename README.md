# School Quiz App

> A Streamlit quiz application for school subjects, with a large question bank and score tracking.

![Python](https://img.shields.io/badge/Python-3.x-3776AB?logo=python&logoColor=white)
![License](https://img.shields.io/badge/License-MIT-green)


## Features

- Multiple subject banks: pedagogy, technology, science, native language and maths.
- Randomised question order.
- Answer checking with an explanation.
- Score summary at the end.
- Normalises several question formats into one shape.

## Tech Stack

| Layer | Technology |
|---|---|
| UI | Streamlit |
| Data | Python question banks |

## Quick Start

```bash
git clone https://github.com/dastonbek8747/school-quiz-app.git
cd school-quiz-app
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
streamlit run main.py
```

## Project Structure

```
main.py      # Streamlit quiz UI
tests.py     # question banks
```
